### [MAJOR]

**M1. Wards whose names differ only by diacritics get merged `legacyNames`, so 16 wards have wrong old names.**
`scripts/build-admin-units.mjs:61-68` (`matchKey` strips every combining mark via `.normalize("NFD").replace(/\p{M}/gu, "")`), used as the join key at `:135` and `:176`.

The code comment says the goal is only to ignore tone placement (hoà/hòa). In practice it also strips tones and the breve/circumflex/horn. Two different wards in the same province then share one key, and both receive the union of both CSV groups. The "no unmatched CSV group" invariant cannot detect this, because the merged group counts as "used".

Confirmed in `seed/data/administrative-units.json`. Both wards in each pair have identical legacy arrays:
- 04 Hải Phòng: `Xã Cẩm Giang` (10717083) / `Xã Cẩm Giàng` (10717086)
- 10 Thái Nguyên: `Xã Văn Lang` (20709081, Na Rì) / `Xã Văn Lăng` (21511033, Đồng Hỷ)
- 22 Quảng Ngãi: `Xã Sơn Hạ` (50513038) / `Xã Sơn Hà` (50513040); `Xã Ba Tô` (50525049) / `Xã Ba Tơ` (50525051)
- 28 Đồng Nai: `Xã Lộc Thành` (70705060) / `Xã Lộc Thạnh` (70705064)
- 29 HCM: `Xã Thạnh An` (70143168, a Cần Giờ island) / `Xã Thanh An` (71113062, ex-Dầu Tiếng). Thạnh An now lists "Xã An Lập, Huyện Dầu Tiếng", etc.
- 27 Tây Ninh: `Xã Tân Thành` (70905083) / `Xã Tân Thạnh` (80109016)
- 31 Đồng Tháp: `Xã Tân Thành` (80305059) / `Xã Tân Thạnh` (80311075)

Impact: this breaks the AC "phường/xã… có `legacyNames`" (official data must be correct, and the task notes forbid invented ward lists). Through rentals `searchText` (ERD §6), a search for "Dầu Tiếng" would return Cần Giờ listings, which violates the intent of LGL-01. The slug suffixes `-2` on these wards show the same collision.

Fix:
- (a) Keep tones and base-letter diacritics in the key. Normalise only tone placement (old vs new style, e.g. `oà↔òa`, `oá↔óa`, `uỳ↔ùy`, `oẻ↔ỏe`), plus case, whitespace and `Tp`.
- (b) Add a guard: `fail()` when two xlsx wards in the same province produce the same key.
- (c) Any new spelling mismatches that surface must be added as explicit aliases. This changes the user-approved "16 aliases", so report the new alias list to the user before committing.
- (d) Add a unit test: no two wards in the same province have identical `legacyNames` arrays, or assert on a specific case such as HCM `Xã Thạnh An` not containing "Dầu Tiếng".
- (e) Regenerate the JSON.
